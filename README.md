# ReadyUpAgents

We build n8n templates that help a business keep its Gmail inbox under control. They sort incoming email with AI, draft replies for you to review, and follow up with leads that went quiet.

## What we make

- **Inbox triage:** labels new Gmail by priority so the important messages surface first.
- **Lead follow-up:** spots real sales leads and drafts timely follow-ups.
- **Real estate:** inbox triage and lead pursuit built for agents.
- **Indie game developers:** Steam review digests and key request triage that flags likely scams.

Every template runs in your own n8n with your own Gmail and OpenAI credentials. OpenAI usage is billed by OpenAI and is usually small for a typical inbox.
